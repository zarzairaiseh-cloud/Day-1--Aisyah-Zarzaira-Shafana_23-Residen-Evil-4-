## Dokumentasi Kegiatan Workshop

### 1. Rangkuman Materi Workshop
* **Prompt Engineering:** Mempelajari cara merancang instruksi yang efektif bagi AI menggunakan struktur yang baik seperti Role, Task, Context, dan Format agar menghasilkan respon yang tepat, relevan, dan berkualitas.
* **Git vs GitHub:** Memahami perbedaan antara Git sebagai sistem version control lokal untuk melacak perubahan, dan GitHub sebagai platform berbasis web untuk menyimpan repository secara online serta mendukung kolaborasi.
* **Git Workflow & Commands:** Mempelajari alur kerja Git mulai dari Working Directory, Staging Area, hingga .git directory (Repository), serta perintah esensial seperti `git init`, `git add`, `git commit`, `git push`, dan `git pull`.

### 2. Poin-Poin Penting & Pengetahuan Baru
* Pentingnya memberikan konteks yang jelas pada prompt AI agar model dapat memberikan hasil yang sesuai dengan kebutuhan spesifik.
* Cara melakukan version control dasar menggunakan Git untuk mencatat siapa, kapan, dan apa saja perubahan yang terjadi pada file.
* Cara menghubungkan project lokal ke remote repository di GitHub dan melakukan sinkronisasi kode.

### 3. Pendapat Pribadi
* Workshop Day 1 ini sangat seru, bermanfaat, dan membuka wawasan baru tentang bagaimana cara menyusun prompt AI yang efektif serta memahami dasar kerja kontrol versi menggunakan Git dan GitHub untuk kolaborasi proyek secara terstruktur.
